# Mazmorra · Descargas

Escapad juntos. Desconfiad de todos.

Instaladores oficiales de la app de PC de **Mazmorra**, el party game de escape room con roles ocultos.
Siempre apuntan a la última versión:

| Sistema | Descarga |
|---|---|
| Windows | [Mazmorra-Windows-Setup.exe](https://github.com/Rozas22/mazmorra-releases/releases/latest/download/Mazmorra-Windows-Setup.exe) |
| macOS (Intel y Apple Silicon) | [Mazmorra-macOS.dmg](https://github.com/Rozas22/mazmorra-releases/releases/latest/download/Mazmorra-macOS.dmg) |
| Linux | [Mazmorra-Linux.AppImage](https://github.com/Rozas22/mazmorra-releases/releases/latest/download/Mazmorra-Linux.AppImage) |

Todas las versiones: [Releases](https://github.com/Rozas22/mazmorra-releases/releases).

> Los instaladores aún no están firmados. En Windows, si aparece SmartScreen: *Más información → Ejecutar de todas formas*.
> En macOS, la primera vez: clic derecho sobre la app → *Abrir*.
